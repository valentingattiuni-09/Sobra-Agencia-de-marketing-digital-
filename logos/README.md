# Logos Brinda — Publicidad que regala

Versiones del logo redibujadas en vector (calidad infinita) y exportadas a PNG de alta resolución (4000 px de lado mayor, fondo transparente salvo las versiones negativas).

## Archivos

| Versión | PNG | SVG (editable) |
|---|---|---|
| Logo horizontal | `png/brinda-logo-horizontal.png` | `svg/brinda-logo-horizontal.svg` |
| Logo vertical | `png/brinda-logo-vertical.png` | `svg/brinda-logo-vertical.svg` |
| Isotipo (símbolo) | `png/brinda-isotipo.png` | `svg/brinda-isotipo.svg` |
| Monocromático | `png/brinda-logo-monocromatico.png` | `svg/brinda-logo-monocromatico.svg` |
| Negativo (fondo oscuro) | `png/brinda-logo-negativo.png` | `svg/brinda-logo-negativo.svg` |
| Isotipo negativo | `png/brinda-isotipo-negativo.png` | `svg/brinda-isotipo-negativo.svg` |

Los SVG son vectoriales: se pueden abrir y editar en Illustrator, Figma, Inkscape, etc., y escalar a cualquier tamaño sin perder calidad. El texto está convertido a trazados, así que no requieren tener la fuente instalada.
